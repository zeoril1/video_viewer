# Медиатека, новинки и просмотр

Новые возможности плеера и лимиты сервера описаны в [playback.md](playback.md).

## Что появилось

- **Моё** (`/library.html`): «Смотреть позже», просмотренные фильмы/сериалы/сезоны, подписки, новые непросмотренные серии за 30 дней и предпочтения просмотра. Списки и настройки хранятся в PostgreSQL отдельно для каждого аккаунта.
- **Календарь** (`/calendar.html`): месяц, общий вид, фильмы, сериалы, премьеры либо премьеры вместе с сериями, фильтр подписок. Данные TMDB загружаются постранично; кнопка «Загрузить ещё» добавляет события следующей страницы. Подписки проверяются отдельно, поэтому их серии не зависят от попадания в популярные результаты общего календаря.
- **Что посмотреть** (`/discover.html`): тип, жанр, минимальный рейтинг, длительность, исключение просмотренного, случайный выбор из загруженных вариантов. Из карточки открываются рекомендации TMDB, трейлер и подборки фильмов по актёру/режиссёру.
- **Автовыбор**: предпочтение озвучки, потолок качества и размера всей раздачи. Сначала предпочитается нужная озвучка, затем наличие сидов и качество. Источники с неизвестными размером/качеством остаются кандидатами; ручной выбор доступен на карточке.
- **Восстановление**: после ошибки плеера или длительного ожидания появляется предложение сменить источник. Поиск сохраняет позицию, качество и предпочтение озвучки; для сериала принимается только точное совпадение сезона и серии. Ручная смена источника отменяет незавершённое восстановление. Монтаж разных релизов может немного отличаться.
- **Новые серии**: подписка на карточке сериала; раздел в медиатеке исключает просмотренные сезоны и учтённые в истории эпизоды. Наличие подходящей раздачи проверяется отдельной кнопкой, включая проверку файла конкретной серии. Дата эфира сама по себе не означает доступность источника.
- **Вход на ТВ**: на `/device.html` получить код; на телефоне открыть `/device.html?mode=approve`, войти в аккаунт и явно подтвердить код. Код действует 10 минут и используется один раз. Телевизору выдаётся собственная HttpOnly-сессия. QR-код не требуется.
- **IPTV**: избранные и недавние каналы, предыдущий канал, сетка EPG на 6 часов с листанием времени и каналов, архив завершённых передач. История EPG сохраняется до 7 дней, даже если провайдер перестаёт публиковать прошлые передачи.

## Настройка и обновление

Новые таблицы `personal_items`, `device_links` и поля catch-up каналов создаются существующим `EnsureSchema` при старте сервисов. Существующие таблицы пользователей и истории не заменяются.

Из каталога проекта:

```sh
docker compose up -d --build
```

Для календаря, рекомендаций и трейлеров нужен существующий `TMDB_API_KEY` или `TMDB_ACCESS_TOKEN` в `.env`. Без него личные списки, вход по коду и IPTV работают, а страницы новинок показывают сообщение о недоступности данных. Даты — основные даты релиза/эфира TMDB, а не гарантированные даты цифрового релиза в конкретной стране. Трейлер открывается на YouTube, когда он есть в метаданных.

Архив требует поддержки у провайдера. Поддерживаются Xtream `tv_archive`/`tv_archive_duration` и M3U `catchup-days`, `catchup-source` с режимом `default`/`append`. Шаблоны: `{utc}`, `{utcend}`, `{start}`, `{end}`, `{duration}` (Unix seconds/длительность в секундах). Специфические форматы других провайдеров не угадываются. После обновления синхронизируйте плейлист в админке IPTV, чтобы загрузить его возможности архива. EPG за прошлые дни появится из данных провайдера либо накопится при последующих синхронизациях. Ссылки и пароли провайдера проксируются сервером.

## Проверки

```sh
go test ./...
node --test tests/*.test.cjs
```

`FEATURE_TEST_DATABASE_URL` включает интеграционные тесты входа по коду, личных списков и IPTV. Тесты создают собственные случайные схемы и удаляют только их. Используйте отдельную тестовую PostgreSQL. `TEST_DATABASE_URL` включает существующий интеграционный тест кеша сезонов.

`tests/features.browser.cjs` запускает локальный сервер с тестовыми API и проверяет настоящие страницы в Chromium. Нужен установленный Playwright; путь к модулю можно передать через `PLAYWRIGHT_MODULE`, путь к браузеру — через `CHROMIUM_PATH`. Скриншоты по умолчанию пишутся в `/output` (можно переопределить `FEATURE_SCREENSHOTS`). Эти тесты проверяют интерфейс, а не доступность внешних раздач и IPTV-провайдера.

Метаданные используют официальные API TMDB: [Discover movies](https://developer.themoviedb.org/reference/discover-movie), [Discover TV](https://developer.themoviedb.org/reference/discover-tv), [Season details](https://developer.themoviedb.org/reference/tv-season-details).
