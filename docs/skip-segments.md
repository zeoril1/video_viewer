# Пропуск заставок, пересказов и титров

На страницах фильма и просмотра в плеере доступна кнопка «Пропуск». Для пересказа, заставки и титров независимо выбирается режим «Выключено», «Кнопка» или «Автоматически». По умолчанию показывается кнопка в момент соответствующего участка. Настройки сохраняются в аккаунте; без входа действуют до закрытия страницы.

## Автоматическое определение

1. Во время существующего запроса дорожек ffprobe также читает главы видео. Распознаются английские и русские названия: Intro/Opening/OP/Заставка, Recap/Previously/В предыдущих сериях, Credits/Ending/ED/Титры. Проверяются длительность и расположение участка; пронумерованные главы не считаются разметкой. Перекрывающиеся главы требуют подтверждения для автопропуска.
2. Для серии с известными сезоном, номером и длительностью сервер запрашивает TheIntroDB. Поиск идёт отдельно от запуска потока; отсутствие отметок или ошибка сервиса не мешает просмотру. По возможности используется TMDB ID, иначе IMDb ID. Результаты возвращаются в абсолютных секундах исходного файла.
3. Ваши исправления для конкретного файла имеют приоритет по типу участка. Далее используются главы этого файла, затем внешние отметки. Несколько блоков титров сохраняются отдельно, чтобы не перескакивать через сцену между ними.

Внешние отметки относятся к другому возможному релизу. Они доступны как кнопки; автоматический пропуск включается после подтверждения или исправления границ для текущего файла. Длительность сама по себе не подтверждает совпадение монтажа. Автоматически сопоставлять музыку разных серий, распознавать текст титров и анализировать речь эта версия пока не умеет.

## Исправление отметок

В панели «Пропуск» можно подтвердить найденный участок, изменить границы, удалить его или добавить новый. Время задаётся в секундах, в формате минуты:секунды или часы:минуты:секунды; кнопки «Текущая позиция» берут абсолютное время плеера. После удаления отметки можно восстановить найденную разметку соответствующего типа.

Правки хранятся через существующие настройки аккаунта в PostgreSQL. Ключ содержит нормализованный infohash и фактический индекс видеофайла, включая автоматический выбор файла. Другая серия или раздача получает отдельные отметки; изменения имени раздачи и URL трекера не меняют ключ. Правки личные и не отправляются во внешнюю базу.

После обычного пропуска в течение 15 секунд доступно действие «Вернуться». Оно и ручная перемотка назад подавляют повторный автопропуск соответствующего участка на время текущего просмотра. Для участка титров, заканчивающегося вместе с файлом, действие завершает серию, сохраняет конечную позицию и запускает существующий переход к следующей серии. ffmpeg с позицией за концом файла не запускается. В комнате пропуском управляет ведущий; участники получают его новую позицию или серию.

## Настройки сервера

В окружении сервиса `catalog`:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `SEGMENTS_EXTERNAL_ENABLED` | `true` | Поиск готовых отметок; `false` оставляет главы и личные правки |
| `THEINTRODB_API_KEY` | пусто | Необязательный ключ, публичное чтение работает без него |

Запросы к TheIntroDB имеют таймаут три секунды, ограниченный размер ответа, ограничение параллельности и частоты, общий кэш до 512 запросов и обработку `Retry-After`. Успешные результаты кэшируются на 24 часа, отсутствие отметок — на 10 минут; кэш живёт до перезапуска `catalog`. Видео дополнительно не скачивается и новые процессы анализа не запускаются.

`GET /api/films/{id}/tracks` теперь также возвращает `segments` и `media_key`. `GET /api/films/{id}/segments?season=1&episode=2&duration=2100&tmdb=123` возвращает внешнюю разметку и статус `ready`, `not_found`, `unavailable` или `disabled`. Длительность и границы в этом API измеряются в секундах; миллисекунды внешнего API преобразуются на сервере.

## Обновление и проверка

Для применения обновления пересоберите сервисы `catalog`, `stream` и `gateway`:

```sh
docker compose up -d --build catalog stream gateway
go test ./...
node --test tests/*.test.cjs
node tests/skip_segments.browser.cjs
```

Браузерная проверка использует Playwright и локальные фикстуры, без обращения к реальным торрентам. При необходимости задайте `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH`. Поддержка конкретного сериала зависит от наличия именованных глав или отметок во внешней базе; точность границ реальных релизов следует проверить при просмотре.
